## מטרת הפרויקט

אפליקציה אחת לשני בני הזוג, על הטלפונים, לניהול משק הבית:

- מעקב הוצאות אוטומטי מהבנקים ומכרטיסי האשראי של שניהם
- שיוך כל הוצאה לבן הזוג שנשא בה, עם חלוקה גמישה לכל הוצאה
- תקציב חודשי לכל אחד ולהוצאות המשותפות
- חשבונות דירה והוראות קבע
- לו"ז זוגי משותף עם זיהוי חפיפות והתנגשויות
- רשימת קניות משותפת עם השוואת עלות סל בין סופרים

## לימוד AWS (לשלב 3)

> **בקשה של עומר:** כשמגיעים לשלב 3, להסביר את AWS לעומק למי שמשתמש בו בפעם הראשונה, במטרה להציג את הידע אחר כך (קורות חיים, LinkedIn, ראיונות). להסביר כל רכיב לפני שמשתמשים בו: מה הוא, למה צריך אותו כאן, איך מגדירים בקונסול ובקוד.

נושאים לכסות, לפי הסדר:

- [ ] **יסודות:** חשבון, root מול IAM, MFA, Regions ו-Availability Zones, מודל התמחור, AWS Budgets
- [ ] **IAM:** Users, Roles, Policies, עקרון ההרשאה המינימלית (least privilege)
- [ ] **EC2:** סוגי מכונות (t4g מול t3, ARM מול x86), AMI, EBS, Security Groups, מצבי running/stopped וחיוב
- [ ] **SSM:** Parameter Store לסודות, Session Manager לגישה בלי SSH
- [ ] **EventBridge Scheduler:** תזמון, cron expressions, הרשאות להדלקה וכיבוי
- [ ] **CloudWatch:** לוגים, מטריקות, התראות על כשל
- [ ] **Infrastructure as Code:** להגדיר את הכל כקוד (Terraform או AWS CDK) כדי שאפשר להציג ב-GitHub
- [ ] **לתיק העבודות:** דיאגרמת ארכיטקטורה, README, ניסוח ל-LinkedIn ולקורות החיים

## מודל נתונים (תמצית)

| טבלה | שדות עיקריים |
| --- | --- |
| `members` | id, name |
| `accounts` | id, member_id, provider, last4, type |
| `transactions` | id, account_id, paid_by, date, amount, merchant, category_id, tag (apartment/personal), kind, status (provisional/pending/completed), source, external_hash, installment_*, review_match_id |
| `transaction_splits` | transaction_id, member_id, amount |
| `settlements` | transfer_tx_id, original_tx_id, amount |
| `categories` | id, name, parent_id |
| `category_rules` | pattern, category_id, tag |
| `budgets` | month, member_id (null = משותף), category_id, amount |
| `recurring` | merchant, expected_amount, day_of_month, kind |
| `bills` | type, period, amount, due_date, paid |
| `calendar_connections` | member_id, provider (google/apple), account, calendars[], encrypted_token |
| `events` | member_id, connection_id, external_id, ical_uid, start, end, title |
| `shopping_items` | name, barcode, qty, added_by, done |
| `store_prices` | chain, store_id, barcode, price, promo, updated_at |

## מושגים

- **Worker** — תוכנית רקע בלי ממשק, שרצה לפי לוח זמנים: מושכת עסקאות, אירועים ומחירים, מעבדת אותם ושומרת ב-Supabase. הטלפונים רק קוראים את התוצאה.
- **PWA** — אתר שמותקן כאפליקציה על מסך הבית, בלי App Store.
- **CalDAV** — הפרוטוקול היחיד של אפל לגישה חיצונית ליומן iCloud.
- **RLS** — Row Level Security: חוקי הרשאה ברמת השורה במסד, כך שרק שניכם רואים את הנתונים.
